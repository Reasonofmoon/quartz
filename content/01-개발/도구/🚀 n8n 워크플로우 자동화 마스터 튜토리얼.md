## [🎯 Phase 1: 기초 개념 이해 (10분)]

### 💡 n8n의 핵심 철학 이해

n8n은 **"노드 기반 워크플로우 자동화"** 플랫폼입니다. 마치 레고 블록을 조립하듯 각각의 기능 블록(노드)을 연결하여 복잡한 자동화를 구현합니다.

**핵심 개념 3가지:**

```yaml
1. 트리거 (Triggers): 워크플로우를 시작하는 이벤트
   - Form 제출, 이메일 수신, 스케줄, API 호출 등
   - 🌟 포인트: 모든 자동화는 트리거에서 시작됩니다

2. 액션 (Actions): 각 단계에서 수행하는 작업
   - 데이터 변환, API 호출, 파일 처리, 메시지 전송 등
   - 🌟 포인트: 각 노드는 독립적인 기능을 수행합니다

3. 데이터 흐름 (Data Flow): 노드 간 정보 전달
   - JSON 형태의 배열로 데이터 전달
   - 🌟 포인트: 각 노드는 0개 이상의 "아이템" 배열을 출력합니다
```

**실제 업무 적용 예시:**

- 고객 문의 폼 → 자동 분류 → 담당자 알림 → CRM 등록
- 주문 접수 → 재고 확인 → 결제 처리 → 배송 준비 알림
- 파일 업로드 → 바이러스 검사 → 압축 → 백업 저장

### ⚡ Step 2: 조건부 로직 구현 (8분)

# ⚡ Step 2: 스마트 조건부 로직 구현

## 2.1 IF 노드 추가

```
1. Form Trigger 노드 옆 "+" 버튼 클릭
2. "Flow" 섹션에서 "IF" 노드 선택
3. 노드 연결선이 자동으로 생성됨을 확인
```

## 2.2 조건 설정: 7일 이내 긴급 요청 판별

### 🎯 비즈니스 로직

"희망 설치일이 오늘로부터 7일 이내면 긴급 처리, 그 외는 일반 처리"

### 📊 조건 구성

```yaml
Condition 1:
  Value 1: {{ $json.preferred_install_date }}  # 드래그&드롭으로 매핑
  Operation: "is before or equal to"
  Value 2: {{ $now().plus(7, 'days').toDateTime() }}
```

## 2.3 데이터 매핑 상세 가이드

### 🔗 Value 1 설정 (희망 설치일)

```
1. Value 1 필드 클릭
2. 왼쪽 데이터 패널에서 "preferred_install_date" 드래그
3. 표현식 모드로 자동 전환: {{ $json.preferred_install_date }}
4. 하단에 실제 날짜 값 미리보기 확인
```

### ⏰ Value 2 설정 (7일 후 기준일)

```
1. Value 2를 "Expression" 모드로 변경
2. 다음 표현식 입력:
   {{ $now().plus(7, 'days').toDateTime() }}

표현식 해석:
- $now(): 현재 시간
- .plus(7, 'days'): 7일 추가
- .toDateTime(): 날짜 객체로 변환
```

## 2.4 노드 이름 변경 (가독성 향상)

```
IF 노드 이름을: "7일 이내 긴급 요청?"
→ 나중에 워크플로우를 다시 볼 때 의도가 명확해짐
```

## 2.5 False 브랜치 처리

```
1. False 출력에서 "+" 클릭
2. "Helpers" → "No Operation" 선택
3. 노드 이름을: "일반 처리 대기열"
```

## ✅ 테스트 검증

```yaml
테스트 시나리오 1 (긴급):
- 희망일: 오늘 + 2일
- 예상 결과: True 브랜치로 라우팅

테스트 시나리오 2 (일반):  
- 희망일: 오늘 + 10일
- 예상 결과: False 브랜치로 라우팅
```

